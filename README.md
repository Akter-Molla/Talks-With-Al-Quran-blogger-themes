# 📖 Talks With Al Quran — Blogger Themes

**Talks With Al Quran** হলো ইসলামিক কনটেন্ট, আল-কুরআন, তাফসির, হাদিস এবং Quran Chatbot-ভিত্তিক ওয়েবসাইট তৈরির জন্য তৈরি একটি আধুনিক **Blogger/Blogspot Theme Collection**।

এই রিপোজিটরিতে বিভিন্ন সময়ে তৈরি ও আপডেট করা **Talks With Al Quran**-এর বিভিন্ন Blogger Theme, Quran-related JSON data এবং প্রয়োজনীয় resource সংরক্ষণ করা হয়েছে।

> **কথা বলুন আল-কুরআনের সাথে — জানুন, বুঝুন এবং কুরআনের আলোকে জীবন গড়ুন।**

## ✨ প্রধান বৈশিষ্ট্য

এই Theme Collection-এর বিভিন্ন version-এ প্রয়োজন অনুযায়ী বিভিন্ন ফিচার যুক্ত করা হয়েছে।

### 📖 Quran Features

* 🕋 আল-কুরআন পড়ার সুবিধা
* 🔎 Quran Search
* 📜 আয়াত প্রদর্শন
* 📚 তাফসির দেখানোর সুবিধা
* 🎨 Color-coded Tajweed
* 🔤 Word-by-Word Quran
* 🌐 অনুবাদ প্রদর্শনের সুবিধা
* 🔗 Similar / Related Ayah দেখানোর সুবিধা
* 📌 Quran-related তথ্য ও resource ব্যবহারের সুবিধা

### 🤖 Quran Chatbot

**Talks With Al Quran** প্রকল্পের অন্যতম প্রধান উদ্দেশ্য হলো ব্যবহারকারীর জন্য কুরআনভিত্তিক একটি সহজ প্রশ্নোত্তর ব্যবস্থা তৈরি করা।

সম্ভাব্য সুবিধাগুলোর মধ্যে রয়েছে:

* কুরআন সম্পর্কে প্রশ্ন করা
* সংশ্লিষ্ট আয়াত খুঁজে পাওয়া
* আয়াতের বাংলা অনুবাদ প্রদর্শন
* তাফসিরের তথ্য প্রদর্শন
* Related / Similar Ayah দেখানো
* ইসলামিক জ্ঞান অনুসন্ধান

> **নোট:** Chatbot-এর উত্তর ব্যবহার করার ক্ষেত্রে নির্ভরযোগ্য Quran ও Tafsir source যাচাই করা গুরুত্বপূর্ণ।

## ধাপ ২ — Blogger Theme Backup

Theme পরিবর্তন করার আগে অবশ্যই বর্তমান Blogger Theme-এর backup রাখুন।

**Blogger Dashboard → Theme → Backup**

তারপর বর্তমান Theme-এর XML file সংরক্ষণ করুন।

---

## ধাপ ৩ — নতুন Theme Upload

Blogger Dashboard থেকে:

```text
Theme
   ↓
Customize / Edit HTML
   ↓
Theme XML Replace
   ↓
Save
```

আপনার পছন্দের `XML` Theme code ব্যবহার করুন।

# 📚 Quran Data

এই প্রজেক্টে Quran-related বিভিন্ন data format ব্যবহার করা হয়েছে।

### Word-by-Word Quran

```text

```

### Tajweed Data


Tajweed ও Uthmani text-related তথ্যের জন্য এই ধরনের data resource ব্যবহার করা হয়েছে।

### Translation

```text

```

Word-by-Word translation-related data সংরক্ষণের জন্য ব্যবহৃত হয়েছে।
